# ローカル文字起こしWebアプリ（Gemini API 連携）

自分用・少人数向けに、ローカル環境（`127.0.0.1`）で動作する音声・動画文字起こしWebアプリケーションです。  
**Gemini API（無料枠対応）** と **Files API** を利用し、1〜2時間超の講義や会議動画でも完走率と文字起こし精度を高める工夫を組み込んでいます。

## 主な特徴

- **完全ローカル起動（`127.0.0.1` バインド）:** 
  外部ネットワークから直接アクセスされないため、APIキーや作業中のデータをローカル環境内に閉じて安全に扱えます。
- **長時間（1〜2時間超）向けの設計:**
  - **30分（1,800秒）単位の自動分割処理:** `ffmpeg` がインストールされている場合、音声をモノラル・16kHz・64kbps の MP3 に圧縮変換しつつ 30 分ごとに分割し、パート単位で順次文字起こしして結合します（`ffmpeg` 未導入時は一括処理へ自動フォールバック）。
  - **Files API 活用と即時クリーンアップ:** 大きな音声・動画も Base64 ではなく Files API でアップロードし、`ACTIVE` 状態になるまで待機してから生成を実行。処理完了後（またはエラー時）にクラウド側・ローカル一時ファイルの両方を確実に削除します。
- **精度を高めるプロンプト設計:**
  - 「要約・省略・中略の禁止」「`[MM:SS]` タイムスタンプ付与」「話者（話者A・話者Bなど）の区別」「推測捏造の抑制（聞き取り不明箇所は `[聞き取り不明]` と明記）」を徹底。
  - **専門用語・固有名詞・話者メモ**を入力でき、表記ゆれや聞き間違いを補正します。
- **わかりやすい進捗表示と出力機能:**
  - アップロード進捗率（`%`）とサーバー側での文字起こしステータスをリアルタイム表示。
  - 文字起こし結果のワンクリックコピーおよび `.txt` ファイルダウンロードに対応。

## 事前準備・必要な環境

### 1. Node.js
- **推奨バージョン:** v18.0.0 以上（`package.json` で `"type": "module"` の ES Modules 構文を使用しているため）
- 確認コマンド:
  ```bash
  node -v
  ```

### 2. Gemini API キー
- [Google AI Studio](https://aistudio.google.com/) にアクセスし、API キーを発行してください。
- **無料枠（Free Tier）での運用:** 請求先アカウント（クレジットカード）を紐づけない無料枠のまま利用すれば、利用上限に達した際にエラーが返るだけで、意図せず課金されるリスクはありません。

### 3. ffmpeg（任意・長時間分割処理を使う場合に強く推奨）
- 30分単位の自動分割処理と音声圧縮を有効にするには、OS に `ffmpeg` コマンドがインストールされ、パス（`PATH`）が通っている必要があります。
- **Windows:**
  ```powershell
  winget install Gyan.FFmpeg
  ```
  ※インストール後、ターミナル（コマンドプロンプトや PowerShell）を再起動してください。
- **macOS (Homebrew):**
  ```bash
  brew install ffmpeg
  ```
- **Linux (Ubuntu / Debian):**
  ```bash
  sudo apt update && sudo apt install -y ffmpeg
  ```
- 確認コマンド:
  ```bash
  ffmpeg -version
  ```

## セットアップと起動手順

### ステップ 1: プロジェクトフォルダの作成とファイル配置
任意の場所に `transcribe-app` フォルダを作成し、以下のファイルを配置します。
- `package.json`
- `.env.example`
- `server.js`
- `public/index.html`

### ステップ 2: 依存パッケージのインストール
ターミナルを開き、プロジェクトフォルダに移動してパッケージをインストールします。

```bash
cd transcribe-app
npm install
```

### ステップ 3: 環境変数の設定
`.env.example` をコピーして `.env` ファイルを作成します。

```bash
# macOS / Linux / Git Bash の場合
cp .env.example .env

# Windows コマンドプロンプトの場合
copy .env.example .env
```

作成した `.env` ファイルをテキストエディタで開き、取得した `GEMINI_API_KEY` を記入します。

```env
GEMINI_API_KEY=AIzaSyYourActualApiKeyHere
PORT=3000
```

### ステップ 4: サーバーの起動
以下のコマンドでローカルサーバーを起動します。

```bash
npm start
```

ターミナルに次のように表示されれば起動成功です。
```text
文字起こしアプリ起動中: http://127.0.0.1:3000
```

### ステップ 5: ブラウザでアクセス
Google Chrome や Edge などのブラウザを開き、アドレスバーに以下の URL を入力します。

```text
http://127.0.0.1:3000
```
※終了する場合は、ターミナル上で `Ctrl + C` を押してください。

## 使い方

1. **音声または動画ファイルを選択**
   - 「音声または動画ファイルを選択」ボタンから、講義や会議のファイル（MP4, MOV, MKV, MP3, M4A, WAV など）を指定します。
2. **専門用語・固有名詞・話者メモを入力（任意）**
   - 専門用語、製品名、略語、登壇者・参加者名などを入力しておくと、AI が文脈に合わせて漢字変換や表記ゆれを補正します。
   - **入力例:**
     ```text
     講義名：情報工学概論
     用語：アルゴリズム、計算量、ビッグオー記法、二分探索
     話者：講師＝佐藤教授、質問者＝学生
     ```
3. **分割処理オプションの確認**
   - 30分を超える長時間の講義・会議では、**「30分単位で自動分割処理する」** にチェックを入れたままにしてください（`ffmpeg` が利用可能な場合、自動で分割・圧縮が行われます）。
4. **文字起こし開始**
   - 「文字起こし開始」ボタンをクリックします。
   - まずブラウザからローカルサーバーへの **アップロード進捗（`0%〜99%`）** が表示され、続いて **「文字起こし中...」** のステータスに切り替わります（1〜2時間の動画の場合、完了まで数分かかることがあります）。
5. **結果の確認・コピー・保存**
   - 処理が完了すると、「文字起こし結果」のテキストエリアに全文が出力されます。
   - **「テキストをコピー」** でクリップボードへコピー、**「.txt でダウンロード」** でテキストファイルとして保存できます。

## 処理フローと技術仕様

### システム構成とデータフロー

1. **フロントエンド（`public/index.html`）:**
   - バニラ HTML / CSS / JavaScript で構成（ビルド不要）。
   - `XMLHttpRequest` を使用して `POST /api/transcribe` へ `multipart/form-data` を送信し、`upload.onprogress` イベントでアップロード進捗率を算出・描画します。
2. **ファイル受信（`server.js` / Multer）:**
   - OS の一時ディレクトリ（`os.tmpdir()/gemini-transcribe-uploads`）にアップロードファイルを一時保存します（最大ファイルサイズ上限: `4GB`）。
3. **音声抽出・チャンク分割（`ffmpeg`）:**
   - `useChunking === 'true'` かつ `ffmpeg` が検出された場合、以下のパラメータで映像を除去（`-vn`）し、30分（1800秒）ごとのモノラル音声に分割します。
     - チャンネル数: `1`（モノラル）
     - サンプリングレート: `16000Hz`
     - ビットレート: `64k`（MP3形式）
4. **Gemini Files API へのアップロードと待機:**
   - 各チャンク（または元ファイル）を `ai.files.upload()` で Google の一時ストレージへアップロードします。
   - ファイル状態（`state`）が `PROCESSING` の間は 3 秒ごとに `ai.files.get()` でポーリングし、`ACTIVE` になるのを待機します。
5. **テキスト生成（`gemini-2.5-flash`）:**
   - `ai.models.generateContent()` を呼び出し、パート番号・開始目安時間・専門用語メモ・厳守ルールを組み込んだプロンプトと共に文字起こしを実行します。
6. **クリーンアップ（`finally` ブロック）:**
   - 成功・失敗にかかわらず、`ai.files.delete()` で Gemini 側のファイルを削除し、`fs.rmSync()` でローカルの一時ファイルおよび分割ディレクトリを完全に削除します。

### ポート番号の変更方法
他の開発ツール等でポート `3000` をすでに使用している場合は、`.env` ファイルの `PORT` の値を変更してサーバーを再起動してください。
```env
PORT=3080
```

## 精度・完走率を高めるための運用Tips

- **画面（スライド・板書）の映像情報が不要な場合:**
  動画ファイル（MP4等）をそのままアップロードしても動作しますが、あらかじめ音声のみ（M4A / MP3）のファイルを用意すると、ブラウザからの転送時間やディスク消費を大幅に削減できます。
- **無料枠のレート制限（RPM / RPD / TPM）への配慮:**
  Gemini API の無料枠には、1分あたりのリクエスト数（RPM）や1日あたりのリクエスト数（RPD）に上限があります。30分分割で2時間の動画を処理すると 4 回分のリクエストが発生するため、短時間に何本も連続して実行せず、時間をおいて処理してください。
- **専門用語メモを積極的に活用する:**
  大学の講義シラバスや会議のアジェンダにあるキーワードをコピー＆ペーストして「専門用語・固有名詞・話者メモ」欄に入れておくだけで、同音異義語の誤変換が劇的に減少します。
- **後段での議事録化・要約:**
  本アプリは「発言を省略せず忠実に全文を起こすこと」に特化しています。出力された `.txt` ファイルを別のプロンプトで「議事録フォーマットに要約して」と指示すると、元の発言の取りこぼしがない高品質な議事録が作れます。

## よくあるトラブルと対処法

| 症状・エラー内容 | 考えられる原因 | 対処法 |
| :--- | :--- | :--- |
| 起動時に `環境変数 GEMINI_API_KEY が設定されていません。` と出て終了する | `.env` ファイルが存在しない、または `GEMINI_API_KEY=` の後ろが空欄になっている | `.env.example` をコピーして `.env` を作成し、有効な API キーを記入してから `npm start` を再実行してください。 |
| 分割にチェックを入れたのに `一括処理（ffmpeg未検出のためフォールバック）` と表示される | `ffmpeg` がインストールされていない、または環境変数 `PATH` が反映されていない | `ffmpeg` をインストール後、**ターミナルを一度閉じて開き直してから** `npm start` を実行してください。 |
| 文字起こし中に `429 Too Many Requests` などのエラーが出る | Gemini API 無料枠のレート制限（1分あたり・1日あたりの上限）に達した | 数分待ってから再試行するか、1日の上限に達した場合はリセット（太平洋時間の午前0時）以降に再度実行してください。 |
| 長時間処理の途中でネットワークエラーになる | PC がスリープ状態に入った、またはインターネット接続が一時的に切れた | 長時間ファイルの処理中は PC が自動スリープしないよう電源設定を調整してください。 |
| 他の PC やスマホから `http://[PCのIPアドレス]:3000` で開けない | セキュリティ保護のため `127.0.0.1`（自分自身のPCのみ）で待機しているため | 本アプリはローカル単体利用向けに設計されています。少人数LAN内で共有する場合は、`server.js` のバインドアドレス変更に加えて必ずアクセス制限や認証を導入してください。 |

## セキュリティとプライバシー上の注意

- **API キーの厳重管理:** `.env` ファイルにはあなたの Gemini API キーが含まれます。GitHub 等へアップロードする場合は、必ず `.gitignore` に `.env` を追加し、公開リポジトリにコミットしないでください。
- **無料枠利用時のデータ取り扱い:** Gemini API の無料枠（Free Tier）を使用する場合、送信された音声・動画データやプロンプトが Google のサービス改善・モデル学習に利用される可能性があります。機密性の高い社内会議や個人情報を含む音声を扱う場合は、Google AI Studio の利用規約およびデータ利用ポリシーを確認のうえ運用してください。

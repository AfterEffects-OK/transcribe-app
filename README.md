# ローカル文字起こしWebアプリ（Gemini API 連携）

自分用・少人数向けに、ローカル環境（`127.0.0.1`）で動作する音声・動画文字起こしWebアプリケーションです。  
**Gemini API（無料枠対応）** と **Files API** を利用し、1〜2時間超の講義や会議動画でも完走率と文字起こし精度を高める工夫を組み込んでいます。

## 主な特徴

- **完全ローカル起動（`127.0.0.1` バインド）:**  
  外部ネットワークから直接アクセスされないため、APIキーや作業中のデータをローカル環境内に閉じて安全に扱えます。
- **ブラウザ上の簡単セットアップ（`.env` 自動保存・接続テスト付き）:**  
  APIキー未設定のままサーバーを起動でき、初回アクセス時に自動で開くセットアップ画面からキーの接続テストと `.env` への自動保存が行えます。後からヘッダー右上の「API設定」ボタンでいつでも変更可能です。
- **長時間（1〜2時間超）向けの設計:**
  - **30分（1,800秒）単位の自動分割処理:** `ffmpeg` がインストールされている場合、音声をモノラル・16kHz・64kbps の MP3 に圧縮変換しつつ 30 分ごとに分割し、パート単位で順次文字起こしして結合します（`ffmpeg` 未導入時は一括処理へ自動フォールバック）。
  - **Files API 活用と即時クリーンアップ:** 大きな音声・動画も Base64 ではなく Files API でアップロードし、`ACTIVE` 状態になるまで待機してから生成を実行。処理完了後（またはエラー時）にクラウド側・ローカル一時ファイルの両方を確実に削除します。
- **精度を高めるプロンプト設計:**
  - 「要約・省略・中略の禁止」「`[MM:SS]` タイムスタンプ付与」「話者（話者A・話者Bなど）の区別」「推測捏造の抑制（聞き取り不明箇所は `[聞き取り不明]` と明記）」を徹底。
  - **専門用語・固有名詞・話者メモ**を入力でき、表記ゆれや聞き間違いを補正します。
- **わかりやすい進捗表示と出力機能:**
  - アップロード進捗率（`%`）とサーバー側での文字起こしステータスをリアルタイム表示。
  - 文字起こし結果のワンクリックコピーおよび `.txt` ファイルダウンロードに対応。

## 事前準備・必要な環境

### 1. Node.js
- **推奨バージョン:** v18.0.0 以上（`package.json` で `"type": "module"` の ES Modules 構文を使用しているため）
- 確認コマンド:
  ```bash
  node -v
  ```

### 2. Gemini API キー
- [Google AI Studio](https://aistudio.google.com/) にアクセスし、API キーを発行してください。
- **無料枠（Free Tier）での運用:** 請求先アカウント（クレジットカード）を紐づけない無料枠のまま利用すれば、利用上限に達した際にエラーが返るだけで、意図せず課金されるリスクはありません。

### 3. ffmpeg（任意・長時間分割処理を使う場合に強く推奨）
- 30分単位の自動分割処理と音声圧縮を有効にするには、OS に `ffmpeg` コマンドがインストールされ、パス（`PATH`）が通っている必要があります。
- **Windows:**
  ```powershell
  winget install Gyan.FFmpeg
  ```
  ※インストール後、ターミナルや起動スクリプトを再起動してください。
- **macOS (Homebrew):**
  ```bash
  brew install ffmpeg
  ```
- **Linux (Ubuntu / Debian):**
  ```bash
  sudo apt update && sudo apt install -y ffmpeg
  ```
- 確認コマンド:
  ```bash
  ffmpeg -version
  ```

## セットアップと起動手順

### 方法 A: 自動セットアップスクリプトを使う（推奨・簡単）

#### Windows の場合
1. プロジェクトフォルダ内の **`setup-and-start.bat`** をダブルクリックします。
2. Node.js / `ffmpeg` の自動チェックと、初回のみ `npm install`（依存パッケージの自動導入）が実行されます。
3. ローカルサーバー起動後、自動的にブラウザで `http://127.0.0.1:3000` が開きます。

#### macOS / Linux の場合
1. 初回のみターミナルで実行権限を付与して起動します。
   ```bash
   cd transcribe-app
   chmod +x setup-and-start.sh
   ./setup-and-start.sh
   ```
2. 初回のみ `npm install` が自動実行され、ブラウザで `http://127.0.0.1:3000` が開きます。

---

### 方法 B: 手動コマンドでセットアップ・起動する場合

1. **プロジェクトフォルダへ移動し、依存パッケージをインストール**
   ```bash
   cd transcribe-app
   npm install
   ```
2. **ローカルサーバーを起動**（`.env` が未作成でもそのまま起動できます）
   ```bash
   npm start
   ```
   ターミナルに次のように表示されれば起動成功です。
   ```text
   文字起こしアプリ起動中: http://127.0.0.1:3000
   ```
3. **ブラウザでアクセス**  
   Google Chrome や Edge などのブラウザで `http://127.0.0.1:3000` を開きます。

※終了する場合は、ターミナル上で `Ctrl + C` を押してください（Windows のバッチ経由で別ウィンドウ起動した場合はサーバーウィンドウを閉じます）。

## 使い方

### 1. 初回 API キー登録（セットアップモーダル）
1. ブラウザでアプリを開くと、APIキー未設定時は自動的に **「Gemini API セットアップ」モーダル** が表示されます。
2. Google AI Studio で取得した API キーを入力し、**「接続テストして保存」** をクリックします。
3. Gemini API への接続確認が成功すると、プロジェクト直下の `.env` ファイルに自動で保存され、ヘッダーのバッジが `APIキー: 設定済み` に変わります。
   - 後からキーを変更したい場合は、画面右上の **「API設定」** ボタンからいつでも再設定できます。

### 2. 音声・動画の文字起こし実行
1. **音声または動画ファイルを選択**  
   「音声または動画ファイルを選択」から、講義や会議のファイル（MP4, MOV, MKV, MP3, M4A, WAV など）を指定します。
2. **専門用語・固有名詞・話者メモを入力（任意）**  
   専門用語、製品名、略語、登壇者・参加者名などを入力しておくと、AI が文脈に合わせて漢字変換や表記ゆれを補正します。
   ```text
   例：
   講義名：情報工学概論
   用語：アルゴリズム、計算量、ビッグオー記法、二分探索
   話者：講師＝佐藤教授、質問者＝学生
   ```
3. **分割処理オプションの確認**  
   30分を超える長時間の講義・会議では、**「30分単位で自動分割処理する」** にチェックを入れたままにしてください（ヘッダーの `ffmpeg` バッジが「利用可能」になっていれば自動分割・圧縮が行われます）。
4. **文字起こし開始**  
   「文字起こし開始」ボタンをクリックすると、ブラウザからローカルサーバーへの **アップロード進捗（`0%〜99%`）** が表示され、続いて **「文字起こし中...」** のステータスに切り替わります（1〜2時間の動画の場合、完了まで数分かかることがあります）。
5. **結果の確認・コピー・保存**  
   完了後、「文字起こし結果」のテキストエリアに全文が出力されます。**「テキストをコピー」** または **「.txt でダウンロード」** から保存してください。

## 処理フローと技術仕様

### API エンドポイント一覧（`server.js`）

| メソッド・パス | 役割 |
| :--- | :--- |
| `GET /api/status` | APIキーの設定有無（マスク済み表示）と `ffmpeg` の利用可否を返却します。 |
| `POST /api/settings` | 入力された APIキーで `gemini-2.5-flash` のメタデータ取得テストを行い、有効であれば `.env` へ保存してメモリ上のクライアント設定を更新します。 |
| `POST /api/transcribe` | 音声・動画ファイルを受信し、必要に応じて `ffmpeg` で分割後、Gemini Files API 経由で文字起こしを実行します。 |

### バックエンド処理の流れ

1. **フロントエンド（`public/index.html`）:**  
   ビルド不要のバニラ HTML / CSS / JavaScript で構成。`XMLHttpRequest` の `upload.onprogress` イベントでアップロード進捗率を描画します。
2. **ファイル受信（Multer）:**  
   OS の一時ディレクトリ（`os.tmpdir()/gemini-transcribe-uploads`）にアップロードファイルを一時保存します（最大ファイルサイズ上限: `4GB`）。
3. **音声抽出・チャンク分割（`ffmpeg`）:**  
   `useChunking === 'true'` かつ `ffmpeg` が検出された場合、映像を除去（`-vn`）し、30分（`1800`秒）ごとのモノラル・`16000Hz`・`64k` の MP3 チャンクを生成します。
4. **Gemini Files API へのアップロードと待機:**  
   各チャンク（または元ファイル）を `ai.files.upload()` で Google の一時ストレージへアップロードし、`state === 'ACTIVE'` になるまで 3 秒間隔でポーリング待機します。
5. **テキスト生成（`gemini-2.5-flash`）:**  
   `ai.models.generateContent()` を呼び出し、パート番号・開始目安時間・専門用語メモ・厳守ルールを組み込んだプロンプトで文字起こしを実行します。
6. **クリーンアップ（`finally` ブロック）:**  
   成功・失敗にかかわらず、`ai.files.delete()` で Gemini 側のファイルを削除し、`fs.rmSync()` でローカルの一時ファイルおよび分割ディレクトリを完全に削除します。

### ポート番号の変更方法

他の開発ツール等でポート `3000` をすでに使用している場合は、`.env` ファイルの `PORT` の値を変更してサーバーを再起動してください。

```env
PORT=3080
```

## 精度・完走率を高めるための運用Tips

- **画面（スライド・板書）の映像情報が不要な場合:**  
  動画ファイル（MP4等）をそのままアップロードしても動作しますが、あらかじめ音声のみ（M4A / MP3）のファイルを用意すると、ブラウザからの転送時間やディスク消費を大幅に削減できます。
- **無料枠のレート制限（RPM / RPD / TPM）への配慮:**  
  Gemini API の無料枠には、1分あたりのリクエスト数（RPM）や1日あたりのリクエスト数（RPD）に上限があります。30分分割で2時間の動画を処理すると 4 回分のリクエストが発生するため、短時間に連続で何本も投入せず、時間をおいて処理してください。
- **専門用語メモを積極的に活用する:**  
  講義シラバスや会議のアジェンダにあるキーワードを「専門用語・固有名詞・話者メモ」欄に入れておくだけで、同音異義語やカタカナ語の誤変換が大幅に減少します。
- **後段での議事録化・要約:**  
  本アプリは「発言を省略せず忠実に全文を起こすこと」に特化しています。出力された `.txt` ファイルを別のプロンプトで「議事録フォーマットに要約して」と指示すると、元の発言の取りこぼしがない高品質な議事録が作れます。

## よくあるトラブルと対処法

| 症状・エラー内容 | 考えられる原因 | 対処法 |
| :--- | :--- | :--- |
| 初回アクセス時にセットアップ画面が出る / `APIキー: 未設定` と表示される | `.env` に有効な `GEMINI_API_KEY` がまだ登録されていない | モーダルに Google AI Studio の API キーを入力し、「接続テストして保存」を実行してください。 |
| 「APIキーの検証に失敗しました」と表示される | キーのコピー漏れ・余分な空白・無効化されたキーである | Google AI Studio でキーを再確認し、前後に空白が入っていないか確認して再度保存してください。 |
| 分割にチェックを入れたのに `一括処理（ffmpeg未検出のためフォールバック）` と表示される | `ffmpeg` がインストールされていない、または環境変数 `PATH` が反映されていない | `ffmpeg` をインストール後、**ターミナルや起動スクリプトを一度閉じて開き直してから**再起動してください。 |
| 文字起こし中に `429 Too Many Requests` などのエラーが出る | Gemini API 無料枠のレート制限（1分あたり・1日あたりの上限）に達した | 数分待ってから再試行するか、1日の上限に達した場合はリセット（太平洋時間の午前0時）以降に再度実行してください。 |
| 長時間処理の途中でネットワークエラーになる | PC がスリープ状態に入った、またはインターネット接続が一時的に切れた | 長時間ファイルの処理中は PC が自動スリープしないよう電源設定を調整してください。 |
| 他の PC やスマホから `http://[PCのIPアドレス]:3000` で開けない | セキュリティ保護のため `127.0.0.1`（自分自身のPCのみ）で待機しているため | 本アプリはローカル単体利用向けに設計されています。少人数LAN内で共有する場合は、`server.js` のバインドアドレス変更に加えて必ずアクセス制限や認証を導入してください。 |

## セキュリティとプライバシー上の注意

- **API キーの厳重管理:** 自動生成される `.env` ファイルにはあなたの Gemini API キーが含まれます。GitHub 等へアップロードする場合は、必ず `.gitignore` に `.env` と `node_modules/` を追加し、公開リポジトリにコミットしないでください。
- **無料枠利用時のデータ取り扱い:** Gemini API の無料枠（Free Tier）を使用する場合、送信された音声・動画データやプロンプトが Google のサービス改善・モデル学習に利用される可能性があります。機密性の高い社内会議や個人情報を含む音声を扱う際は、Google AI Studio の利用規約およびデータ利用ポリシーを確認のうえ運用してください。
